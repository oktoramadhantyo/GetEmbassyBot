# Log Magang — 28 September 2026

**Proyek:** GetEmbassy Bot
**Deskripsi:** Otomasi pengecekan kualitas jaringan Embassy dan status Password di
gladius.telkom.co.id lewat Telegram. User kirim nomor, bot mengirim screenshot hasil.

---

## 1. Tujuan Hari Ini

1. Memindahkan bot dari Railway ke server lokal, karena Railway tidak aktif.
2. Melakukan debugging alur otomatis `/embassy` dan `/password` di halaman Gladius.

---

## 2. Yang Berhasil Dicapai

### 2.1 Migrasi Server ke Lokal

- Mengganti endpoint Railway dengan server lokal `http://127.0.0.1:8080`.
- Menambah direktif `@connect 127.0.0.1` pada metadata userscript.
- Membuat `start_bot.bat` dengan fitur:
  - auto-restart bila bot crash,
  - pencatatan seluruh output ke `logs\bot.log`,
  - proteksi anti 2 instance (menolak start bila port 8080 sudah dipakai).
- Menambah folder `logs/` ke `.gitignore`.
- **Verifikasi:** endpoint `/health` merespons `{"ok": true}`, serta `getMe` dan
  `getUpdates` sama-sama membalas HTTP 200.

## 3. Analisis Akar Masalah

Berdasarkan penelusuran `logs\bot.log` dan pembacaan kode userscript, ditemukan
7 akar masalah:

| # | Akar Masalah | Dampak |
|---|---|---|
| 1 | Gladius memunculkan dialog native `window.alert` saat data kosong | Dialog native membekukan seluruh eksekusi JavaScript halaman. Script tidak bisa polling antrian, tidak bisa mengklik tombol, dan tidak bisa mengambil screenshot. |
| 2 | `@require html2canvas` menunda eksekusi userscript | Berpotensi membuat override `alert` terpasang terlambat. |
| 3 | `tungguTenang()` hanya membandingkan panjang teks halaman | Selesai dalam ~1 detik saat Gladius masih menunggu XHR, sehingga data dibaca terlalu dini. |
| 4 | `bacaPaket()` menyisir `div`/`span`/`li` tanpa batas | Teks notifikasi ikut tertangkap dan dianggap sebagai nilai paket yang terisi. |
| 5 | `lfu_ok` ditulis `true` tanpa verifikasi | Caption menyatakan Last Five Usage berhasil padahal panelnya tidak pernah terbuka. |
| 6 | Timeout kirim 30 detik, sedangkan unggah bot 120 detik | `ConnectionAbortedError`; badge menampilkan "Gagal" padahal foto sudah sampai ke Telegram. |
| 7 | `bacaStatusPassword()` mengembalikan kalimat "tidak ditemukan" | String tersebut ikut masuk ke caption dan menyesatkan, karena data sebenarnya ada namun belum ter-render. |

## 7. Catatan Keamanan

- `TELEGRAM_BOT_TOKEN` dan `AGENT_SECRET` dibaca dari environment variable, dan
  file `.env` sudah terdaftar di `.gitignore` sehingga tidak ikut ter-commit.
- Nilai `AGENT_SECRET` pada userscript memang berupa nilai literal agar bisa
  dibandingkan dengan sisi bot. Karena repository ini bersifat publik, nilai tersebut
  sebaiknya dirotasi setelah proses debugging selesai.
